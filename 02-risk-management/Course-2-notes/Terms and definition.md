# Course 2: Play It Safe (Risk Management)

## Key Acronyms & Shortforms

* **AI (Artificial Intelligence)** - Technology integrated into security tools to enhance threat terminology recognition, dashboard visualization, and data storage capabilities.
* **APT (Advanced Persistent Threat)** - A security threat where an unauthorized actor maintains persistent, undetected access to a system over an extended period.
* **BEC (Business Email Compromise)** - A targeted email attack vector managed through specialized organizational incident playbooks.
* **CCTV (Closed-Circuit Television)** - A physical security control used for video surveillance and monitoring physical locations.
* **CISA (Cybersecurity and Infrastructure Security Agency)** - U.S. government agency that maintains the Known Exploited Vulnerabilities Catalog.
* **CSF (Cybersecurity Framework)** - Guidelines created by NIST to help organizations prepare for regulatory compliance and security audits.
* **CTF (Cyber Threat Framework)** - A U.S. government framework providing a standardized language for describing and sharing cyber threat activity.
* **GDPR (General Data Protection Regulation)** - European Union regulations dictating strict controls over how personally identifiable information is processed and protected.
* **HIPAA (Health Insurance Portability and Accountability Act)** - A U.S. law requiring healthcare entities to secure patient medical records and private health data.
* **HITRUST (Health Information Trust Alliance)** - A widely accepted cybersecurity framework used to manage risk and maintain regulatory compliance.
* **IOC (Indicator of Compromise)** - Evidence or log artifacts (such as malicious domain names or IP addresses) that indicate potential system compromise.
* **IoT (Internet of Things)** - Interconnected physical devices with internet connectivity that expand an organization's overall attack surface.
* **ISO/IEC (International Organization for Standardization / International Electrotechnical Commission)** - International standardization bodies responsible for global security frameworks such as ISO/IEC 27001.
* **JPCERT/CC (Japan Computer Emergency Response Team Coordination Center)** - An international organization providing vulnerability handling and response guidelines.
* **LAN (Local Area Network)** - A local computer network structure linking devices within a distinct area.
* **MDR (Managed Detection and Response)** - A managed security service whose alerts can be ingested and automated by SOAR platforms.
* **ML (Machine Learning)** - Advanced data-processing algorithms used within SIEM tools to automate threat detection and analysis.
* **NCSC (National Cyber Security Center)** - The UK government organization offering incident management response playbooks.
* **NTLM (New Technology LAN Manager)** - A suite of Microsoft network authentication protocols targeted by LAN-based exploit techniques.
* **OISF (Open Information Security Foundation)** - The non-profit foundation responsible for developing and maintaining the open-source Suricata engine.
* **OWASP (Open Web Application Security Project / Open Worldwide Application Security Project®)** - An open community publishing secure design principles and top web application risk listings.
* **RMF (Risk Management Framework)** - A structured process developed by NIST to guide organizations through identifying and managing risk.
* **SOAR (Security Orchestration, Automation, and Response)** - Tools and workflows designed to automate responses to repetitive security events flagged by SIEMs.
* **SSRF (Server-Side Request Forgery)** - A web application vulnerability that manipulates a server into reading or updating backend resources.

## Key Tools, Systems & Vulnerabilities

* **Chronicle** - A cloud-native SIEM tool developed by Google for retaining, searching, and analyzing log data.
* **Log4Shell** - A severe Java-based vulnerability enabling remote attackers to execute arbitrary code and gain control of connected devices.
* **PetitPotam** - An authentication theft attack targeting Windows NTLM protocols over local area networks.
* **ProxyLogon** - A pre-authenticated remote code execution vulnerability affecting Microsoft Exchange servers.
* **Splunk** - A proprietary SIEM platform offered as Enterprise or Cloud solutions to monitor and analyze log data.
* **Suricata** - An open-source network analysis and threat detection tool maintained by OISF.
* **ZeroLogon** - A critical exploit affecting Microsoft's Netlogon authentication protocol.
