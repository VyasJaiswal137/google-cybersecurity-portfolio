# Course 1: Foundations of Cybersecurity

> 🔑 **Key Terms & Acronyms Cheat Sheet** (Simplified for Easy Revision)

---

## 🛡️ Core Concepts & Roles

| Term | Full Name / Description | Plain English Meaning |
| :--- | :--- | :--- |
| **CIA Triad** | Confidentiality, Integrity, Availability | A core model used to protect data by keeping it secret (Confidentiality), accurate (Integrity), and available when needed (Availability)[cite: 1]. |
| **CISSP** | Certified Information Systems Security Professional | A well-known cybersecurity certification divided into 8 main security areas[cite: 1]. |
| **CSIRT** | Computer Security Incident Response Team | A dedicated team that responds to and fixes security breaches[cite: 1]. |
| **IT** | Information Technology | The computers, systems, and networks used by an organization that security analysts protect[cite: 1]. |
| **SOC Analyst** | Security Operations Center Analyst | An entry-level job focused on watching network activity, searching for threats, and stopping cyberattacks[cite: 1]. |

## 📜 Frameworks, Regulations & Compliance

| Term | Full Name / Description | Plain English Meaning |
| :--- | :--- | :--- |
| **AICPA** | American Institute of Certified Public Accountants | An organization that created SOC 1 and SOC 2 audit reports to check financial and data security risks[cite: 1]. |
| **CIP** | Critical Infrastructure Protection | Security rules that power companies and energy grid operators are required by law to follow[cite: 1]. |
| **CIS** | Center for Internet Security | A non-profit group that gives clear, step-by-step security rules to protect systems against attacks[cite: 1]. |
| **FedRAMP** | Federal Risk and Authorization Management Program | A US government program that makes sure cloud services meet strict safety standards[cite: 1]. |
| **FERC-NERC** | Federal Energy Regulatory Commission - NERC | An organization that checks power grid companies to make sure they follow cybersecurity laws[cite: 1]. |
| **GDPR** | General Data Protection Regulation | A law in Europe that protects personal data privacy and forces companies to report data breaches within 72 hours[cite: 1]. |
| **HIPAA** | Health Insurance Portability and Accountability Act | A US law that protects patient health records and stops health data from being shared without permission[cite: 1]. |
| **HITRUST** | Health Information Trust Alliance | A security framework created to help healthcare companies follow HIPAA laws[cite: 1]. |
| **ICJ** | International Court of Justice | A global court that sets strict rules on when a country or group can legally hack back after a cyberattack[cite: 1]. |
| **ISO** | International Organization for Standardization | An organization that sets global rules and standards for technology and business management[cite: 1]. |
| **NIST** | National Institute of Standards and Technology | A US agency that creates guidelines and frameworks used worldwide to keep systems safe[cite: 1]. |
| **NIST CSF** | NIST Cybersecurity Framework | Guidelines created to help companies plan, block, and manage cyber risks[cite: 1]. |
| **NIST RMF** | NIST Risk Management Framework | A step-by-step process for building security into computer systems from start to finish[cite: 1]. |
| **PCI DSS** | Payment Card Industry Data Security Standard | International security rules companies must follow to safely handle credit cards and stop fraud[cite: 1]. |
| **SOC Reports** | System and Organization Controls (Type 1 & 2) | Audit reports that check who has access to company data, financial rules, and overall safety[cite: 1]. |

## ⚙️ Tools, Systems & Programming

| Term | Full Name / Description | Plain English Meaning |
| :--- | :--- | :--- |
| **CISA** | Cybersecurity & Infrastructure Security Agency | A US agency that offers free security tools and advice to help protect important systems[cite: 1]. |
| **IDS** | Intrusion Detection System | Software that watches network activity and warns security teams when an intruder or attack is spotted[cite: 1]. |
| **OWASP** | Open Web Application Security Project | A free security group that publishes the top 10 most critical security risks for websites[cite: 1]. |
| **SIEM** | Security Information & Event Management | Software that collects logs from all computers into one place and automatically alerts analysts to suspicious activity[cite: 1]. |
| **SQL** | Structured Query Language | A programming language used to search, update, and pull data from large databases[cite: 1]. |

## ⚠️ Threats, Attacks & Data Types

| Term | Full Name / Description | Plain English Meaning |
| :--- | :--- | :--- |
| **APT** | Advanced Persistent Threat | Highly skilled hackers who secretly break into networks and stay hidden for a long time[cite: 1]. |
| **BEC** | Business Email Compromise | A fake email attack where hackers pretend to be someone you trust (like a boss) to trick you into sending money[cite: 1]. |
| **PHI** | Protected Health Information | Private medical data, such as health history, care plans, or medical bill records[cite: 1]. |
| **PII** | Personally Identifiable Information | Basic personal information that can identify someone, like a full name, address, or phone number[cite: 1]. |
| **SPII** | Sensitive Personally Identifiable Information | High-risk personal information that requires extra protection, like Social Security or credit card numbers[cite: 1]. |
| **USB** | Universal Serial Bus | A standard physical plug or flash drive, which attackers can drop on the ground with malware to trick people into plugging it in[cite: 1]. |
