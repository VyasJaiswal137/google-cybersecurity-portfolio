# Course 1: Foundations of Cybersecurity

> 🔑 **Key Terms & Acronyms Cheat Sheet** (Simplified for Easy Revision)

---

## 🛡️ Core Concepts & Roles

| Term | Full Name / Description | Plain English Meaning |
| :--- | :--- | :--- |
| **CIA Triad** | Confidentiality, Integrity, Availability | A core model used to protect data by keeping it secret (Confidentiality), accurate (Integrity), and available when needed (Availability). |
| **CISSP** | Certified Information Systems Security Professional | A well-known cybersecurity certification divided into 8 main security areas. |
| **CSIRT** | Computer Security Incident Response Team | A dedicated team that responds to and fixes security breaches. |
| **IT** | Information Technology | The computers, systems, and networks used by an organization that security analysts protect. |
| **SOC Analyst** | Security Operations Center Analyst | An entry-level job focused on watching network activity, searching for threats, and stopping cyberattacks. |

---

## 📜 Frameworks, Regulations & Compliance

| Term | Full Name / Description | Plain English Meaning |
| :--- | :--- | :--- |
| **AICPA** | American Institute of Certified Public Accountants | An organization that created SOC 1 and SOC 2 audit reports to check financial and data security risks. |
| **CIP** | Critical Infrastructure Protection | Security rules that power companies and energy grid operators are required by law to follow. |
| **CIS** | Center for Internet Security | A non-profit group that gives clear, step-by-step security rules to protect systems against attacks. |
| **FedRAMP** | Federal Risk and Authorization Management Program | A US government program that makes sure cloud services meet strict safety standards. |
| **FERC-NERC** | Federal Energy Regulatory Commission - NERC | An organization that checks power grid companies to make sure they follow cybersecurity laws. |
| **GDPR** | General Data Protection Regulation | A law in Europe that protects personal data privacy and forces companies to report data breaches within 72 hours. |
| **HIPAA** | Health Insurance Portability and Accountability Act | A US law that protects patient health records and stops health data from being shared without permission. |
| **HITRUST** | Health Information Trust Alliance | A security framework created to help healthcare companies follow HIPAA laws. |
| **ICJ** | International Court of Justice | A global court that sets strict rules on when a country or group can legally hack back after a cyberattack. |
| **ISO** | International Organization for Standardization | An organization that sets global rules and standards for technology and business management. |
| **NIST** | National Institute of Standards and Technology | A US agency that creates guidelines and frameworks used worldwide to keep systems safe. |
| **NIST CSF** | NIST Cybersecurity Framework | Guidelines created to help companies plan, block, and manage cyber risks. |
| **NIST RMF** | NIST Risk Management Framework | A step-by-step process for building security into computer systems from start to finish. |
| **PCI DSS** | Payment Card Industry Data Security Standard | International security rules companies must follow to safely handle credit cards and stop fraud. |
| **SOC Reports** | System and Organization Controls (Type 1 & 2) | Audit reports that check who has access to company data, financial rules, and overall safety. |

## ⚙️ Tools, Systems & Programming

| Term | Full Name / Description | Plain English Meaning |
| :--- | :--- | :--- |
| **CISA** | Cybersecurity & Infrastructure Security Agency | A US agency that offers free security tools and advice to help protect important systems. |
| **IDS** | Intrusion Detection System | Software that watches network activity and warns security teams when an intruder or attack is spotted. |
| **OWASP** | Open Web Application Security Project | A free security group that publishes the top 10 most critical security risks for websites. |
| **SIEM** | Security Information & Event Management | Software that collects logs from all computers into one place and automatically alerts analysts to suspicious activity. |
| **SQL** | Structured Query Language | A programming language used to search, update, and pull data from large databases. |

---

## ⚠️ Threats, Attacks & Data Types

| Term | Full Name / Description | Plain English Meaning |
| :--- | :--- | :--- |
| **APT** | Advanced Persistent Threat | Highly skilled hackers who secretly break into networks and stay hidden for a long time. |
| **BEC** | Business Email Compromise | A fake email attack where hackers pretend to be someone you trust (like a boss) to trick you into sending money. |
| **PHI** | Protected Health Information | Private medical data, such as health history, care plans, or medical bill records. |
| **PII** | Personally Identifiable Information | Basic personal information that can identify someone, like a full name, address, or phone number. |
| **SPII** | Sensitive Personally Identifiable Information | High-risk personal information that requires extra protection, like Social Security or credit card numbers. |
| **USB** | Universal Serial Bus | A standard physical plug or flash drive, which attackers can drop on the ground with malware to trick people into plugging it in. |
